Privacy policy for SrvSurvey

SrvSurvey reads Elite Dangerous journal and companion files on your computer to provide its features. SrvSurvey's developer does not operate a service that collects this data.

Optional Inara uploads

Inara uploads are disabled until you save a personal Inara API key for a commander. SrvSurvey then sends supported updates for that commander directly to Inara. These updates may include your commander name and Frontier ID, credits, assets and loans, ranks and reputation, current location and travel, inventories and statistics, ships and loadouts, missions, combat events, suits, community goals, and friends. Credit changes are accumulated locally and reported at session boundaries, on Statistics events when changes are pending, and otherwise no more frequently than hourly, rather than after every transaction.

Your personal Inara API key is stored locally only in the FID-keyed settings file for that commander and is sent only to Inara as part of authenticated API requests. A game session can use only the name, Frontier ID, and key from its own commander profile; changing commanders creates a separate upload session. SrvSurvey does not write the key or complete upload payloads to its log. You can stop new uploads and discard pending events for that commander by choosing Clear Key.

Data sent to Inara is handled under Inara's privacy policy. You can obtain or manage your personal API key in your Inara API settings.
