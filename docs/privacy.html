Privacy policy for SrvSurvey

SrvSurvey does not collect personal data for its developer.

Optional data-sharing features can transmit Elite Dangerous game data to third-party community services. These features are disabled unless you explicitly enable them in Settings.

If you enable EDDN sharing, SrvSurvey sends public game-world data from supported new journal events and the Market, Outfitting, Shipyard, Fleet Carrier Materials, and navigation-route companion files to the Elite Dangerous Data Network. Each upload includes your Commander name as EDDN's uploader identifier, the game and SrvSurvey versions, and public game-world data from the event. EDDN obfuscates the uploader identifier before relaying the data. SrvSurvey removes localized and Commander-specific event fields required to be excluded by the EDDN schemas, and it does not upload journal history read during startup. Uploads are sent without an EDDN account, API key, or access token. If EDDN is temporarily unavailable, unsent messages are stored in a local retry queue under SrvSurvey's application-data folder. They are removed after successful delivery, after a permanent rejection, or when you disable EDDN sharing. Only one running SrvSurvey process can own and rewrite that queue. Uploads pause, active requests are cancelled, and pending messages remain local while multiple Elite Dangerous clients are running, because their shared status and companion files cannot be attributed safely. SrvSurvey also rechecks the shared on-disk consent before each network request so an opt-out from another SrvSurvey process stops delivery.

SrvSurvey is not an official tool for Elite Dangerous and is not affiliated with Frontier Developments. All trademarks and copyright are acknowledged as the property of their respective owners.
